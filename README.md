# Flow Affiliate Ajaib by Sofy (Versi Gemini Vision)

Aplikasi web gratis untuk follower: upload Foto Orang + Foto Produk, Gemini Vision otomatis membaca detail produknya lalu membuat **2 Scene × 10 Detik (total 20 detik)** untuk **Gemini Omni 1.1 Flash (Lama)** & **Omni 1.2 Flash (Terbaru)** lengkap dengan tag `@orang` & `@produk` + Kunci Karakter 100%.

## Cara Upload ke GitHub & Vercel (Tanpa Coding / Lewat Browser)
1. Ekstrak file ZIP ini.
2. Buat repository baru di GitHub (misal: `flow-affiliate-sofy`).
3. Klik **uploading an existing file**, lalu upload `index.html` dan folder `api/` (berisi `analyze.js`) → klik **Commit changes**.
4. Buka **Vercel** → **Add New Project** → Import repo GitHub tadi.
5. Sebelum klik Deploy, buka bagian **Environment Variables**:
   - **Name**: `GEMINI_API_KEY`
   - **Value**: tempel Gemini API Key gratis dari https://aistudio.google.com/apikey
6. Klik **Deploy**! Selesai — follower kamu tinggal buka link Vercel dan langsung pakai gratis tanpa perlu masukin API key!
